Welcome to My Quantified Self Project!

Goal of this project:
- Conduct analysis on my New Year's Resolutions to determine how well I have stuck to my goals.

QuantifiedSelf.ipynb is the main project, but functions are defined in utilities.py for further reference.
Data was recorded in habits.csv and liked_posts.json, final display in final_df.csv for reference.

Machine Learning algorithms and Exploratory Data Analysis are conducted in QuantifiedSelf.ipynb, as well as walkthrough of
how each goal has performed.

Enjoy!
